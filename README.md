# 晚安 · wanan

一个情侣向的睡前陪伴技能：触发后按「一句温柔情话 → 一个谐音梗猜谜小故事 → 一句温柔晚安」三段式输出。

技能名 `wanan`，版本 `1.2.0`。

> **两种用法**：作为 **DSH 插件**一键安装（`skill("wanan")` 可调用），或者作为**纯 Markdown 提示词**复制到任意 AI 助手。内容完全同一份。

## 它解决什么问题

睡前想说点什么，但想不出来——这大概是情侣之间最高频的小尴尬。

这个技能把"睡前话"拆成三段固定结构，每段只做一件事：

1. **情话**负责让人放松（具体、有动作、能念出口）
2. **谐音梗故事**负责让人笑（一本正经铺垫 → 突然拐到亲密的词上）
3. **晚安**负责落地（回扣上一段的词，不凭空起新话题）

三段顺序不能换：先被哄软，再被逗笑，最后被一句晚安送进被窝。

## 怎么用

### 情况一：装成 DSH 插件（推荐）

```sh
dsh plugin --profile web add github:17897693/wanan-skill
```

装好后在会话里直接说「晚安」「哄我睡」等触发词即可，模型会自动调用 `skill("wanan")`。

插件本身**不注册任何工具**，只负责把 `SKILL.md` 装载进技能目录——所以它不会影响你现有的其它插件。

### 情况二：手动放进技能目录

把 `SKILL.md` 与 `references/` 放进技能目录，**文件夹名与 `SKILL.md` 里的 `name` 保持一致**（`wanan`），保持相对路径不变。

`SKILL.md` 顶部 `---` 之间是元数据：

- `name`：技能名，与文件夹名一致
- `version`：版本号
- `description`：触发说明，决定模型什么时候调用它

### 情况三：当作提示词粘贴（给非 DSH 的助手）

用文本编辑器打开 `SKILL.md`，把 `---` 之间的头信息和正文一起复制，粘贴给你的 AI 助手作为自定义指令（系统提示词／角色设定／自定义 GPT 的 Instructions）。

⚠️ **注意**：粘贴方案下，正文里 `references/xxx.md` 这样的相对路径**是失效的**（助手读不到你的本地文件）。要把两个 references 文件的内容**一并粘贴在后面**——素材池能明显提高谐音梗的稳定性，示例则能帮它找准句式。

### 情况四：只当素材库用

`references/pun-pool.md` 本身就是一份整理好的中文谐音词对表（131 条，按落点分组，标了声调档位）。不用 AI，当成写情话的点子库单独翻也有用。

## 设计要点（给想改的人）

- **禁词表是硬的**：正文列了 11 个书面腔词（愿／岁月／星河／温柔以待……），出现即重写。这条是整份文档最重要的约束——它决定了输出像不像"人说的话"。
- **先想谐音，再编故事**：反过来做（先编故事再硬塞读音）一定会生硬。素材池就是为这个顺序准备的。
- **兜底优先级**：排比 ＞ 亲密落点 ＞ 谐音。谐音可以松，前两样不能丢。
- **不用跨会话记忆**：技能明确要求模型不要假装记得昨晚用了什么词。用户主动提起才避开。
- **谐音分三档**：一档读音全同（最省力）、二档只差声调、三档声母韵母有差（备胎）。池子里一档占近一半。

## 备注

- 文件均为 UTF-8 无 BOM、纯 LF 行尾。Windows 记事本、macOS 文本编辑、VS Code、Typora 都能直接打开。
- 若记事本打开后中文显示乱码，是编码问题：改用 VS Code / Typora，或另存为 UTF-8。
- 内容定位是"睡前陪伴"，禁忌章节明确排除了擦边、土味梗与低俗荤梗。
- **隐私**：本技能零依赖、无网络请求、不读写用户文件。所有内容都在 `SKILL.md` 与 `references/` 里，可自行审阅。
