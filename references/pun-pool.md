# 谐音素材池

用法：**先从这里挑词，再编故事。** 挑定答案词之后，把它放进「排比铺垫 → 提问 → 括号点破」的骨架里。

规则：

- **优先挑一档。** 一档最省力，不用赌口音
- **同一次输出内不要重复用词**；用户若提到昨晚用过哪个，避开它（你没有跨会话记忆，不必假装记得）
- 挑完先念一遍，像不像嘴瓢；念着别扭就换行
- 池子里没有合意的，可以照同样的思路自造，但别硬凑
- **声母不同的词对（l/n、f/h、sh/h 这一类）都在三档**，挑之前先看「容易挑错的」那一节

## 档位怎么算

| 档 | 判定 | 例 |
|---|---|---|
| **一档** | 读音完全一样，或取词的一部分而完全一样 | 宝被→宝贝、艾你→爱你 |
| **二档** | 声母、韵母都对得上，只有声调不同 | 报备→宝贝、杯→倍 |
| **三档** | 声母或韵母有差异，念着像但严格不同音 | 箱里→想你、稀饭→喜欢 |

**声调不用抠，声母韵母要抠。** 三档不是不能用，是要先念一遍，别扭就换。

## 附：可以直呼的昵称词（不是谐音）

下面这些本身就是称呼，**不是谐音梗**。它们只能直接用在情话里叫对方，别拿去做猜谜的答案词——猜出来等于没转音，读者会觉得没劲。

**通用**：团子、乖乖、猪猪、崽崽、小可爱、心肝、笨蛋、小傻瓜、小笨蛋、小家伙、憨憨、臭宝、小宝贝、宝贝儿

**偏宠溺**：小懒虫、小馋猫、小祖宗、小冤家、冤家、淘气包、黏人精、小黏糊

**偏俏皮**（关系已经很熟再用，不然会显得油）：臭老公、臭老婆、死鬼

**按关系选**：他/她如果吃「小朋友」这一套就用「小朋友」；吃「先生」「女士」这一套就用正式称呼反转——**正式称呼 + 极亲密的语气**，反差本身就是笑点。

## 容易挑错的（重点）

这几组听着像，但**声母不一样**，属于三档。挑之前先心里过一遍：

| 看着像 | 实际差别 | 声音感受 |
|---|---|---|
| 里 → 你 | l ／ n | 南方话常混，北方话一耳朵就分出来 |
| 箱里 → 想你 | l ／ n | 「想」很准，「你」偏松 |
| 乡里／厢里 → 想你 | l ／ n | 同上，声母是硬伤 |
| 香米 → 想你 | m ／ n | 都是鼻音，但不同声母 |
| 梨不开 → 离不开 | 声母韵母全同 | 一档，放心用 |
| 莲子 → 恋你 | z ／ n | 两个字都不太对，建议不用 |
| 稀饭 → 喜欢 | f ／ h | 依赖口音，普通话里不像 |
| 麻薯 → 马虎 | sh ／ h | 偏松 |
| 甜心 → 点心 | t ／ d | 偏松 |
| 泡泡 → 抱抱 | p ／ b | 偏松，靠画面救 |
| 烤你 → 靠你 | k ／ k，声调不同 | 二档，但「烤你」本身听着怪，**优先用「犒你」** |
| 香煎你 → 想见你 | 声调不同 | 二档，但句子里要真的像在说吃的，不然很跳 |

**规律：声母是最容易出错的地方。** 韵母差一点还能糊过去，声母换了就换了一个字。

## 已知不好使的（别硬用）

- 「亲爱的」——找不到干净的第一、二档词，硬凑很难听，建议绕开
- 「喜欢你」——只有「稀饭」一条路，且是三档、依赖口音，普通话里不响
- 「爱」——单字，落点不完整，要用就用「艾你」凑成「爱你」
- 「老婆」的「婆」找不到同音字，只能靠「老婆饼」整词取前两字
- 抽象名词硬转（心愿、时光、银河）——转出来就是文艺腔，属于本技能的禁忌方向
- 「睡你」「泡你」这类——荤，一律不要
- 「病」「癌」「死」等字开头的同音词——不吉利，再顺也不用
